1. Project Overview
1. Project Overview
Examic Evaluation System
Examic Evaluation System
 is a multi-module web application for managing academic evaluations. It serves three distinct user groups across three modules:
Module
Module
Acronym
Acronym
Purpose
Purpose
Computer-
Based Testing
CBT
CBT
Evaluate candidates who sat computer-delivered exams. Faculty can view exams, view per-candidate
answer scripts, and grade long-answer / rubric-based questions.
Online Script
Marking
OSM
OSM
Digital scanning and marking of physical paper-based scripts. Admin manages papers and rosters;
evaluators mark assigned scripts; reviewers moderate marks.
Evaluation
Flow
EF
EF
End-to-end workflow for term-end and internal assessments. Covers roster creation, synoptic uploads,
marking pallets, data entry, and manual script marking.
The system uses 
role-based privilege gates
role-based privilege gates
 to restrict which users can see which modules and pages. A single user account can hold privileges spanning multiple
modules.

Cache behaviour
Cache behaviour
First call to hasPermission("OSM_FACULTY"):
  → reads state.auth.permissions
  → checks if SUPER_ADMIN is present → short-circuit true
  → else checks if "OSM_FACULTY" is in permissions array
  → stores result in permissionCache Map
  → returns result
Subsequent calls with same key:
  → returns cached result immediately (no array scan)
Cache is cleared on:
  → Login (loginUser.fulfilled)
  → Logout (logout action)
  → Every navigation (PrivilegesUpdater)
  → Whenever permissions change (PrivilegesUpdater useEffect)

Scenario: Faculty logs in and marks an OSM script
1. USER opens /login
   └── LoginPage renders
2. USER submits email + password
   └── dispatch(loginUser({ email, password }))
   └── POST /api/auth/login
   └── Response: { userToken, user: { privileges: ["OSM_FACULTY"], ... } }
   └── authSlice stores user + token in Redux + localStorage
   └── clearPermissionCache()
3. APP navigates to "/"
   └── SmartLandingPage checks:
       canAccessOSM = hasAnyPermission(["OSM_FACULTY"]) → true
       canAccessCBT = hasAnyPermission(["CBT_VIEW_DASHBOARD"]) → false
       → <Navigate to="/evaluation/dashboard" />
4. BROWSER loads /evaluation/dashboard
   └── PrivilegesUpdater fires fetchUserData() (re-syncs privileges)
   └── EvaluationDashboard renders
   └── PrivilegeGate checks permissions:
       - Admin section: user has no OSM_VIEW_ADMIN_DASHBOARD → hidden
       - My Work section: user has OSM_FACULTY → shown
   └── User sees "Internal Assessments" and "Term End Exams" cards
5. USER clicks "Term End Exams"
   └── navigate("/evaluation/term-end")
   └── TermEndDashboard loads
   └── Shows scripts assigned to this faculty (from evaluationFlowService)
6. USER selects a script
   └── navigate("/evaluation/manual-marking/STU-ABC-123")
   └── ManualMarkingPage loads
   └── Fetches student script PDF + marking pallet
   └── PDF rendered via react-pdf / react-konva
   └── Annotations stored in annotationsSlice as user draws
7. USER submits marks
   └── API call to save evaluation
   └── Success toast shown
   └── Navigate back to evaluator dashboard
